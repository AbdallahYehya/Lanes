YouTube connection

Powers Trending and topic lanes. From Google Cloud → Credentials.
Needed for Subscriptions, Liked, and sending the queue to a YouTube playlist.
Add both to the OAuth client in Google Cloud, exactly as shown.

Setup in 6 steps

  1. Open console.cloud.google.com, create a project "Lanes".
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. Credentials → Create credentials → API key. Paste it above.
  4. OAuth consent screen → External → add your Gmail under Test users.
  5. Credentials → Create credentials → OAuth client ID → Web application → add the origin and the redirect URI shown above.
  6. Paste the client ID above, Save, then Sign in.
